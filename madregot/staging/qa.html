Madregot staging: QA entry points

Temporary test copy of the Madregot app for an independent review. It has no server: no AI, no classes, no teacher dashboard, no sync. Every visitor is an anonymous local test user; saved progress stays in this browser under its own key (madregot-staging), separate from the public site.

Each link below loads a ready-made anonymous test student into this browser and opens one screen. With &seed=1 it also sets madregot-seed, so the same exercises come on every load. To start from a clean first visit, use "first visit". Build details: version.json. The app itself: index.html.

The current exercise, with its answer, is available on every lesson screen of this build, with no flag to set: as JSON in the data-qa-item attribute of the <html> element (readable from the page HTML and from scripts that run in an isolated context, for example JSON.parse(document.documentElement.dataset.qaItem).answer), and as window.__madregotItem for scripts that run in the page itself. It updates when the exercise changes. Answer formats: a number; [x, y] for a point; {m, b} for a line; for multiple choice, the index (0-based) of the right choice.
