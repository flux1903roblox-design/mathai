# מדרגות

אפליקציית תרגול מתמטיקה יומי לכיתות ז׳ וח׳, עם עוזר AI (Claude) שמסביר כל טעות.
אפשר לתרגל לבד, או בכיתה עם לוח מורה.

## מה יש באפליקציה

**תרגול במדרגות.** כל נושא בנוי ממדרגות. שתי תשובות נכונות ברצף מעלות מדרגה; אחרי טעות או רמז צריך ארבע, ותרגיל שטעו בו חוזר אחרי שלושה תרגילים. עשר דקות ביום, רצף ימים ונקודות.

**נושאים.** ז׳: מספרים מכוונים, מערכת צירים, זוויות. ח׳: פונקציה קווית (8 מדרגות, לפי החומר מהשיעור: טבלת ערכים, m ו־b, שיפוע מהגרף, שיפוע בין שתי נקודות, משוואת ישר, חיתוך עם הצירים, משולש עם הצירים, נקודת מפגש), משפט פיתגורס, סטטיסטיקה. לכל נושא יש "תזכורת מהשיעור", ובפונקציה קווית גם גרף שמזיזים בו את m ואת b.

**פותרים במחברת.** במקום מקלדת אפשר לכתוב את הדרך באצבע או בעט על דף משובץ. העוזר קורא את הכתב ובודק כל שורה, ואפשר לשלוח את הדף למורה.

**עוזר AI.** מסביר למה טעיתם, עונה על שאלות על כל תרגיל (צ'אט), כותב תרגילים חדשים באותה רמה, ובודק פתרון מצולם.

**מבחנים.**
- *בדיקת מבחן:* מצלמים את דפי המבחן הפתור (עד 8 דפים) או מעלים PDF. העוזר בודק כל שאלה: נכון, נכון בחלקו, טעות או לא נענה.
- *משוב אישי לכל שאלה:* מה בדיוק השתבש אצלכם ולמה, התשובה הנכונה, ופתרון לדוגמה בשלבים.
- *נושאים לחיזוק:* כל שאלה משויכת לנושא ולמדרגה שהיא מתרגלת, כך שההמלצה היא תרגול ממוקד ("פונקציה קווית: חיתוך עם הצירים"), לא רק "לחזור על הנושא".
- *מבחן תרגול להדפסה:* מבחן מהנושאים שבחרתם, ברמה שלכם, עם מפתח תשובות מדויק. כשבודקים אותו, העוזר משווה למפתח ולא פותר לבד.
- *תוכנית לשיפור:* צעדים לפי הסדר. כל נושא חלש מתורגל מהמדרגה שבה ירדו נקודות, והצעד מושלם אחרי ארבע תשובות נכונות שם או מעל. אחר כך מבחן חוזר, ותרגול יומי. הצעד הבא מופיע גם במסך "היום".

**לוח מורה.** מי תרגל היום ובשבוע, טעויות שחוזרות בכיתה, נושאים חלשים מהמבחנים, טבלת מבחנים עם ריבוע לכל שאלה, בקשות עזרה (כולל דף מהמחברת), ואיפוס קוד אישי לתלמיד.

## איך זה בנוי

```
madregot/
  web/      האפליקציה: React + Vite (עברית, מימין לשמאל, מותאם לטלפון)
  worker/   השרת: Cloudflare Worker + מסד D1. שומר את מפתח Claude, כיתות והתקדמות
  shared/   הבקשות ל־Claude, משותפות לשרת ולדפדפן
```

השרת מגיש גם את האפליקציה עצמה, כך שהכול יושב בכתובת אחת (`https://madregot-api.<השם שלכם>.workers.dev`). הבקשות ל־AI עוברות דרך השרת, והמפתח לא מגיע לדפדפן.

**מה נשמר איפה.** התקדמות, מבחנים שנבדקו ומבחני תרגול נשמרים במכשיר (localStorage). בכיתה, השרת שומר גם את התשובות, הרמות, סיכום המבחנים (נושא, תוצאה ומיומנות לכל שאלה, בלי התמונות) ובקשות עזרה. תמונות המבחן נשלחות ל־Claude לבדיקה ולא נשמרות בשרת.

## העלאה לאוויר (Windows)

צריך: Node.js 20 ומעלה, חשבון Cloudflare חינמי, ומפתח API של Anthropic.

```powershell
cd madregot
.\setup.ps1
```

הסקריפט מתקין, מתחבר ל־Cloudflare, יוצר את מסד הנתונים, בונה, מעלה, ובסוף מבקש להדביק את מפתח Claude (הוא נשמר כסוד בשרת). בסוף מופיעה הכתובת של האפליקציה. כדי לבדוק שהעוזר מחובר: `<הכתובת>/api/health` צריך להחזיר `"ai": true`.

עדכונים אחר כך: `.\deploy.ps1` (מריץ בדיקות, בונה ומעלה).

### בלי PowerShell (Mac או Linux)

```bash
cd madregot
npm ci --prefix web && npm ci --prefix worker
cd worker
npx wrangler login
npx wrangler d1 create madregot --binding DB --update-config=false
# העתיקו את ה־database_id מהפלט אל worker/wrangler.toml במקום REPLACE_WITH_DATABASE_ID
npx wrangler d1 execute madregot --remote --file=schema.sql --yes
cd .. && npm run build --prefix web && cd worker
npx wrangler deploy
npx wrangler secret put ANTHROPIC_API_KEY
```

## הגדרות (worker/wrangler.toml)

| משתנה | מה הוא עושה | ברירת מחדל |
|---|---|---|
| `CLAUDE_MODEL` | המודל לכל פעולות העוזר | `claude-opus-5-5` |
| `AI_DAILY_LIMIT` | פעולות AI ביום לתלמיד בכיתה | 40 |
| `SOLO_DAILY_LIMIT` | פעולות AI ביום למכשיר של תלמיד בלי כיתה | 20 |
| `ALLOW_SOLO_AI` | `false` משאיר את העוזר רק לתלמידים בכיתה | `true` |
| `ALLOWED_ORIGINS` | כתובות נוספות שמותר להן לפנות לשרת (פיתוח מקומי, או עותק של האפליקציה שמתארח במקום אחר) | localhost |

אפשרות נוספת לתלמיד שמתרגל לבד: במסך "אני" אפשר להדביק מפתח Claude אישי. אז הבקשות יוצאות ישר מהמכשיר לשירות של Anthropic, בלי השרת.

## פיתוח מקומי

```bash
# חלון 1: השרת
cd madregot/worker
npm ci
echo "ANTHROPIC_API_KEY=sk-ant-..." > .dev.vars     # לא נכנס ל־git
npm run db:init:local
npm run dev                                          # http://127.0.0.1:8787

# חלון 2: האפליקציה
cd madregot/web
npm ci
npm run dev                                          # http://localhost:5173
```

## בדיקות

```bash
npm test --prefix madregot/web      # מחוללי התרגילים (כל מדרגה 300 פעמים), סולם המדרגות, ציון מבחן, נושאים חלשים, התוכנית
npm test --prefix madregot/worker   # צורת הבקשות ל־Claude וקריאת התשובות
```

מה נבדק עד עכשיו: הבדיקות האלה, ובנוסף סיור מלא בדפדפן (Playwright) מול השרת המקומי: הצטרפות לכיתה, תרגול ועליית מדרגה, הסבר טעות, צ'אט, מחברת ובדיקת דף, פונקציה קווית והגרף, העלאת מבחן (תמונות ו־PDF), תוצאות ומשוב, תוכנית לשיפור עד השלמת צעד, מבחן תרגול: יצירה, הדפסה ובדיקה מול המפתח, ולוח המורה. בסיור הזה Claude הוחלף בשרת דמה שמחזיר תשובות קבועות, כדי לבדוק את הצורה של כל בקשה ואת התצוגה. מומלץ לעשות בדיקה אחת עם מפתח אמיתי (מבחן מצולם אמיתי) אחרי ההעלאה.
