# מדרגות

אפליקציית תרגול מתמטיקה יומי לכיתות ז׳ וח׳, עם עוזר AI (Claude) שמסביר כל טעות.
אפשר לתרגל לבד, או בכיתה עם לוח מורה.

## מה יש באפליקציה

**היכרות ובדיקת רמה.** בכניסה הראשונה מדי שואל כמה שאלות קצרות, אחת בכל מסך: שם, כיתה, כמה מהחומר כבר מוכר, כמה זמן ביום מתאים, וקוד כיתה (לא חובה). אחר כך בוחרים: בדיקת רמה קצרה, או להתחיל מהמדרגה הראשונה. הבדיקה מסתגלת: בכל נושא עד 3 שאלות, תשובה נכונה מעלה מדרגה ותשובה שגויה מורידה, ובסוף כל נושא מתחיל מהמדרגה שלכם (עד 9 שאלות לכל הכיתה). אפשר לחזור לבדיקה מהלוח בכל זמן, ומדרגות שכבר נפתחו נשארות פתוחות.

**הלוח שלי.** מסך הבית נפתח בלוח: כמה מדרגות עליתם בכיתה, מדרגות קטנות לכל נושא (כמה הושלמו ואיפה אתם עכשיו), ומצב לכל נושא (הושלם, בדרך, כדאי לחזק, עוד לא התחלנו). מתחת לכל נושא מופיע **מה עוד לא ברור**: טעויות שהאפליקציה זיהתה (למשל "חיברו מרחקים כשהסימנים שונים") ושאלות שירדו עליהן נקודות במבחן שבדקתם, עם כפתור "לתרגל" שפותח שיעור במדרגה המתאימה. טעות יורדת מהלוח אחרי 3 תשובות נכונות בניסיון ראשון באותה מדרגה. מתחת ללוח ממשיכה מפת השיעורים.

**מפת לימוד בסגנון Duolingo.** מסך הבית הוא מסלול מתפתל: כל נושא הוא יחידה בצבע משלה, וכל מדרגה היא עיגול במסלול. שיעור קצר של 8 תרגילים, כפתור "בדיקה" גדול בתחתית, ואחרי כל תשובה פס ירוק (נכון) או אדום (עוד לא). טעות ראשונה: מנסים שוב עם רמז. טעות שנייה: רואים את התשובה, את הדרך ואת ההסבר של העוזר, ותרגיל דומה חוזר בסוף השיעור. כל מדרגה נגמרת אחרי שני שיעורים, וכל יחידה נסגרת בחזרה מעורבת. מי שכבר יודע יכול לקפוץ קדימה במבחן קצר של 5 תרגילים.

**רצף, XP ומשימות, בלי לחץ.** שיעור אחד ביום שומר על הרצף, ובשבת הרצף לא נשבר. מסיימים את שלוש המשימות היומיות ומקבלים הקפאת רצף (עד שתיים) ליום שמפספסים. יעד יומי ב-XP שבוחרים בעצמכם, ו-XP גם על תיקון טעות. אין לבבות או אנרגיה שעוצרים את התרגול, אין טבלת דירוג בין ילדים, ואין הודעות מאשימות. הקמע **מדי** מעודד, וצלילים קצרים (אפשר לכבות) מלווים תשובות וסיום שיעור.

**נושאים.** ז׳: מספרים מכוונים, מערכת צירים, זוויות. ח׳: פונקציה קווית (8 מדרגות, לפי החומר מהשיעור: טבלת ערכים, m ו־b, שיפוע מהגרף, שיפוע בין שתי נקודות, משוואת ישר, חיתוך עם הצירים, משולש עם הצירים, נקודת מפגש), משפט פיתגורס, סטטיסטיקה. לכל נושא יש "תזכורת מהשיעור", ובפונקציה קווית גם גרף שמזיזים בו את m ואת b.

**פותרים במחברת.** במקום מקלדת אפשר לכתוב את הדרך באצבע או בעט על דף משובץ. העוזר קורא את הכתב ובודק כל שורה, ואפשר לשלוח את הדף למורה.

**עוזר AI.** מסביר למה טעיתם, עונה על שאלות על כל תרגיל (צ'אט), כותב תרגילים חדשים באותה רמה, ובודק פתרון מצולם.

**מבחנים.**
- *בדיקת מבחן:* מצלמים את דפי המבחן הפתור (עד 8 דפים) או מעלים PDF. העוזר בודק כל שאלה: נכון, נכון בחלקו, טעות או לא נענה.
- *משוב אישי לכל שאלה:* מה בדיוק השתבש אצלכם ולמה, התשובה הנכונה, ופתרון לדוגמה בשלבים.
- *נושאים לחיזוק:* כל שאלה משויכת לנושא ולמדרגה שהיא מתרגלת, כך שההמלצה היא תרגול ממוקד ("פונקציה קווית: חיתוך עם הצירים"), לא רק "לחזור על הנושא".
- *מבחן תרגול להדפסה:* מבחן מהנושאים שבחרתם, ברמה שלכם, עם מפתח תשובות מדויק. כשבודקים אותו, העוזר משווה למפתח ולא פותר לבד.
- *תוכנית לשיפור:* צעדים לפי הסדר. כל נושא חלש מתורגל מהמדרגה שבה ירדו נקודות, והצעד מושלם אחרי ארבע תשובות נכונות שם או מעל. אחר כך מבחן חוזר, ותרגול יומי. התוכנית נמצאת במסך המשימות ובמסך המבחנים.

**לוח מורה.** מי תרגל היום ובשבוע, טעויות שחוזרות בכיתה, נושאים חלשים מהמבחנים, טבלת מבחנים עם ריבוע לכל שאלה, בקשות עזרה (כולל דף מהמחברת), ואיפוס קוד אישי לתלמיד.

## איך זה בנוי

```
madregot/
  web/      האפליקציה: React + Vite (עברית, מימין לשמאל, מותאם לטלפון)
  worker/   השרת: Cloudflare Worker + מסד D1. שומר את מפתח Claude, כיתות והתקדמות
  shared/   הבקשות ל־Claude, משותפות לשרת ולדפדפן
```

השרת מגיש גם את האפליקציה עצמה, כך שהכול יושב בכתובת אחת (`https://madregot-api.<השם שלכם>.workers.dev`). הבקשות ל־AI עוברות דרך השרת, והמפתח לא מגיע לדפדפן.

**מה נשמר איפה.** התקדמות, מבחנים שנבדקו ומבחני תרגול נשמרים במכשיר (localStorage). בכיתה, השרת שומר גם את התשובות, הרמות, סיכום המבחנים (נושא, תוצאה ומיומנות לכל שאלה, בלי התמונות) ובקשות עזרה. תמונות המבחן נשלחות ל־Claude לבדיקה ולא נשמרות בשרת.

## האתר ב־GitHub Pages

הגרסה בלי שרת פתוחה לכולם בכתובת https://flux1903roblox-design.github.io/mathai/madregot/
יש בה את מפת השיעורים, השיעורים, המשימות, בדיקת הרמה והלוח. עוזר ה־AI, הצטרפות לכיתה ולוח המורה צריכים את השרת (Cloudflare, למטה), וההתקדמות נשמרת רק במכשיר.

כדי לפרסם גרסה חדשה אחרי שינוי בקוד (Mac או Linux, או Git Bash ב־Windows):

```sh
./madregot/publish-pages.sh
```

הסקריפט בונה את האפליקציה ומחליף רק את התיקייה madregot בענף gh-pages. האתר MathAI שבשורש הענף לא משתנה.

## עותק בדיקה (staging)

`./madregot/publish-staging.sh` מעלה עותק בדיקה זמני לכתובת נפרדת: <https://flux1903roblox-design.github.io/mathai/madregot-staging/>.
הוא בלי שרת (בלי עוזר, כיתות ולוח מורה), שומר התקדמות במפתח משלו (`madregot-staging`) כך שלא נוגע בנתונים של האתר הציבורי, לא נכנס למנועי חיפוש, ומשנה רק את התיקייה `madregot-staging/` בענף `gh-pages`.
העותק נבנה רק מקומיט שכבר נמצא ב־GitHub, ו־`version.json` בתוכו מציין איזה. `qa.html` בתוכו פותח כל מסך וכל מדרגה עם תלמיד בדיקה אנונימי. הסרה: `./madregot/publish-staging.sh --remove`.

## העלאה לאוויר (Windows)

צריך: Node.js 20 ומעלה, חשבון Cloudflare חינמי, ומפתח API של Anthropic.

```powershell
cd madregot
.\setup.ps1
```

הסקריפט מתקין, מתחבר ל־Cloudflare, יוצר את מסד הנתונים, בונה, מעלה, ובסוף מבקש להדביק את מפתח Claude (הוא נשמר כסוד בשרת). בסוף מופיעה הכתובת של האפליקציה. כדי לבדוק שהעוזר מחובר: `<הכתובת>/api/health` צריך להחזיר `"ai": true`.

עדכונים אחר כך: `.\deploy.ps1` (מריץ בדיקות, בונה ומעלה).

### בלי PowerShell (Mac או Linux)

```bash
cd madregot
npm ci --prefix web && npm ci --prefix worker
cd worker
npx wrangler login
npx wrangler d1 create madregot --binding DB --update-config=false
# העתיקו את ה־database_id מהפלט אל worker/wrangler.toml במקום REPLACE_WITH_DATABASE_ID
npx wrangler d1 migrations apply madregot --remote   # שינויים במסד הנתונים רק דרך worker/migrations
cd .. && npm run build --prefix web && cd worker
npx wrangler deploy
npx wrangler secret put ANTHROPIC_API_KEY
```

## הגדרות (worker/wrangler.toml)

| משתנה | מה הוא עושה | ברירת מחדל |
|---|---|---|
| `CLAUDE_MODEL` | המודל לכל פעולות העוזר | `claude-sonnet-5-5` |
| `AI_DAILY_LIMIT` | פעולות AI ביום לתלמיד בכיתה | 40 |
| `SOLO_DAILY_LIMIT` | פעולות AI ביום למכשיר של תלמיד בלי כיתה | 20 |
| `ALLOW_SOLO_AI` | `false` משאיר את העוזר רק לתלמידים בכיתה | `true` |
| `ALLOWED_ORIGINS` | כתובות נוספות שמותר להן לפנות לשרת (פיתוח מקומי, או עותק של האפליקציה שמתארח במקום אחר) | localhost |
| `AI_PAYWALL` | `on` מפעיל את המנוי לעוזר (טעימה חינם, מנוי משפחתי, רישיון כיתה). כל השאר ב־`SUBSCRIPTION.md` | `off` |

מאז המנוי לעוזר, השרת צריך גם את הסודות `AUTH_SECRET` ו־`IP_HASH_SECRET` (כל אחד `openssl rand -hex 32`, עם `npx wrangler secret put`). בלי `IP_HASH_SECRET` השרת עונה `server_config` בפעולות שסופרות לפי רשת (יצירת כיתה, הצטרפות, העוזר בלי כיתה), כי הוא לא שומר כתובות רשת. `setup.ps1` יוצר את שניהם, ו־`deploy.ps1` עוצר לפני הפרסום אם אחד מהם חסר. ב־`/api/health` השדות `netKeys` ו־`auth` אומרים אם הם מוגדרים.

גרסה בלי שרת בכלל (רק תרגול לבד, בלי כיתה ובלי עוזר): בונים עם `VITE_API_URL=none npm run build --prefix web` ומעלים את `web/dist` לכל אחסון של קבצים סטטיים.

אפשרות נוספת לתלמיד שמתרגל לבד: במסך "אני" אפשר להדביק מפתח Claude אישי. אז הבקשות יוצאות ישר מהמכשיר לשירות של Anthropic, בלי השרת.

## פיתוח מקומי

```bash
# חלון 1: השרת
cd madregot/worker
npm ci
echo "ANTHROPIC_API_KEY=sk-ant-..." > .dev.vars     # לא נכנס ל־git
npm run db:migrate:local
npm run dev                                          # http://127.0.0.1:8787

# חלון 2: האפליקציה
cd madregot/web
npm ci
npm run dev                                          # http://localhost:5173
```

## בדיקות

```bash
npm test --prefix madregot/web      # מחוללי התרגילים (כל מדרגה 300 פעמים), מנוע השיעור, המפה, המשימות והרצף, ציון מבחן, התוכנית
npm test --prefix madregot/worker   # צורת הבקשות ל־Claude, המכסות, הכניסה במייל, התשלום, הביטול והסקריפט של הבעלים
npm run test:e2e --prefix madregot/web   # בדפדפן (Playwright): מסך התרגיל ב־14 סוגי תרגילים על 4 מכשירים, המקלדת, מסלולי משתמש, כל המסכים, וצילומי מסך להשוואה
```

`test:e2e` בונה גרסה בלי שרת ומריץ אותה מקומית. אחרי שינוי עיצוב מכוון: מסתכלים על הצילומים החדשים ומעדכנים עם `npm run test:e2e --prefix madregot/web -- --update-snapshots`. רשימת התקלות שנמצאו ותוקנו נמצאת ב־`QA_AUDIT.md`, והתוצאות לפי מסך ומכשיר ב־`QA_MATRIX.md`.

מה נבדק עד עכשיו: הבדיקות האלה, ובנוסף סיור מלא בדפדפן (Playwright) מול השרת המקומי: הצטרפות לכיתה, המפה, שיעור עם טעות ותיקון, מסכי הסיום והרצף, משימות, מבחן קפיצה, הסבר טעות, צ'אט, מחברת ובדיקת דף, פונקציה קווית והגרף, העלאת מבחן (תמונות ו־PDF), תוצאות ומשוב, תוכנית לשיפור עד השלמת צעד, מבחן תרגול: יצירה, הדפסה ובדיקה מול המפתח, ולוח המורה. בסיור הזה Claude הוחלף בשרת דמה שמחזיר תשובות קבועות, כדי לבדוק את הצורה של כל בקשה ואת התצוגה. מומלץ לעשות בדיקה אחת עם מפתח אמיתי (מבחן מצולם אמיתי) אחרי ההעלאה.
